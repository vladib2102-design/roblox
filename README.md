# Brainrot Tycoon

Un joc Roblox multiplayer inspirat de genul „steal a brainrot":

- baze separate pentru pana la 6 jucatori;
- trei tipuri de brainrot cu preturi si venituri diferite;
- achizitionare din magazin sau din zonele Plot;
- furtul brainroturilor altor jucatori cu timp de protectie;
- bani si streak salvate prin DataStore;
- HUD cu venituri, streak si magazin.

## Instalare

1. Instaleaza Rojo.
2. Ruleaza `rojo serve` in radacina proiectului.
3. Conecteaza proiectul la Roblox Studio cu pluginul Rojo.
4. Porneste jocul cu **Start** sau **Start Server**.
